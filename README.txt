YAKABE GAMES 公開用ファイル

GitHubの YAKABE-GAMES リポジトリの一番上に index.html と games フォルダをアップロードしてください。
アップロード後、GitHub Pagesを有効にするとホームページが公開できます。

ファイル構成:
- index.html : ゲーム一覧ページ
- games/yakabe_panic.html : 矢加部パニック
- games/lane_dodge.html : LANE DODGE
- games/bread_challenge.html : 矢加部のパン投げチャレンジ

注意:
- 矢加部パニックはThree.jsをCDNから読み込むため、プレイ時にインターネット接続が必要です。
- 各ゲームのセーブデータは、基本的に遊んだ端末・ブラウザ内に保存されます。
